# AI Job Application Tracker (n8n)

An automation workflow built with **n8n** that receives job applications through a form, reads the applicant's CV, evaluates it with **AI (Google Gemini)**, saves the result in **Google Sheets**, and sends an **accept or reject email** automatically.

## The Problem

A company receives many CVs for one position. Reading all of them by hand takes a lot of time, and replying to every applicant takes even more.

## The Solution

This workflow does the repetitive work automatically:

1. The applicant fills a form and uploads a CV (PDF).
2. The AI reads the CV and gives a score from 0 to 100.
3. The decision is made by a simple rule (score >= 70 means accept).
4. The applicant receives an email with the result.
5. Every application is saved in one Google Sheet for the HR team.

---

## Workflow Overview

```
On form submission
        |
Extract From File (PDF -> text)
        |
Basic LLM Chain (Gemini evaluates the CV)
        |
Code (clean the AI answer -> real JSON)
        |
Google Sheets (Append Row)
        |
       IF (decision == "accept")
      /                        \
  true                        false
Gmail (acceptance)       Gmail (rejection)
```

## Tech Stack

| Tool | Usage |
|------|-------|
| n8n (Cloud) | Workflow automation |
| n8n Form Trigger | Application form + CV upload |
| Extract From File | Convert the PDF CV to text |
| Google Gemini | Evaluate the CV and return a score |
| Code node (JavaScript) | Parse and clean the AI response |
| Google Sheets | Store all applications |
| Gmail | Send accept / reject emails |

## Features

- Application form with CV upload (PDF)
- Automatic CV reading and evaluation by AI
- Score, strengths, weaknesses, and decision for every applicant
- Automatic email reply (accept / reject)
- All applications logged in Google Sheets
- No manual work for HR in the basic flow

## Limitations

- The AI can make mistakes, so it should not be the only decision maker in a real hiring process.
- Only PDF CVs are supported.
- The accept threshold (70) is fixed in the prompt.

## Future Improvements

- Human review step for scores between 60 and 75
- Telegram notification for each new applicant
- Separate sheet for accepted candidates
- Personalized compliment sentence in the acceptance email (generated by the AI)
- Reminder email if the applicant does not reply to the interview invitation
- Error handling with an Error Trigger for failed JSON parsing
